# SBot Engine
**SBot Engine** is the engine used behind **SoTeen Bot** which is dedicated to **[SoTeen Team](https://discord.com)**

This bot is built and designed using Node.js technology stack such as **[TypeScript](https://github.com/microsoft/TypeScript)** and **[Sapphire Framework](https://github.com/sapphiredev)** as the main basis at its core.
